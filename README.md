# Tic Tac Toe

A simple, responsive Tic Tac Toe game built with React, Vite,
and Tailwind CSS.

Play with a friend on the same device, track previous moves through game
history, and switch between light and dark themes.
Current Features

- Two-player local gameplay
- Automatic win and draw detection
- Highlighted winning combination
- Turn indicator for X and O
- Game history with move navigation
- Restart game
- Light and dark themes
- Theme preference saved in the browser
- Responsive and compact interface

Future Improvements

- Play against AI with different difficulty levels
- Online multiplayer with room codes
- Player profiles and game statistics
- Achievements and leaderboards
- Daily challenges
- More board themes and X/O styles
- Sound effects and improved animations

Made for fun. Built for everyone.
